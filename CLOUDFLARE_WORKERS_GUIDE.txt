================================================================================
  NebulaProxy — Cloudflare Workers-এ ডিপ্লয় গাইড (বাংলা)
  ভার্সন: 1.0.0
================================================================================

⚠️  সবার আগে গুরুত্বপূর্ণ সত্য কথা (মনে রাখবেন) ⚠️
------------------------------------------------------------------------------
Cloudflare Workers একটি সার্ভারলেস প্ল্যাটফর্ম। এটা শুধু HTTP অনুরোধ (fetch)
চালাতে পারে। আমাদের NebulaProxy গেটওয়ে কাজ করে "CONNECT" মেথড দিয়ে — অর্থাৎ
ক্লায়েন্ট একটা raw TCP টানেল চায় (HTTPS-এর জন্য CONNECT টানেল, SOCKS ইত্যাদি)।

Cloudflare Workers এটা সমর্থন করে **না**। Workers-এ আপনি অবিরাম (persistent)
TCP socket বা CONNECT টানেল ধরে রাখতে পারবেন না।

তাই পরিষ্কারভাবে বুঝে নিন:
  ❌ Workers-এ পূর্ণ গেটওয়ে (CONNECT + SOCKS tunnel) চালানো সম্ভব না।
  ✅ Workers-এ শুধু "রোটেটিং HTTP API" অংশ চালানো সম্ভব:
     - GET /api/proxy       → একটা রোটেটিং IP দিন
     - GET /api/proxy/list  → সব প্রক্সির তালিকা
     - GET /api/proxy/countries → দেশ অনুযায়ী কাউন্ট

অর্থাৎ: গেটওয়ে (port 8000) চালাতে হলে একটা VPS/সার্ভার লাগবেই।
Workers শুধু আপনার "API লেয়ার" হিসেবে কাজ করবে — সেটাও তখনই, যখন আপনার
আসল সার্ভার ওই API গুলো দেবে।

--------------------------------------------------------------------------------
পার্ট ১: Cloudflare Workers কীভাবে কাজ করে (সংক্ষেপ)
--------------------------------------------------------------------------------
1. Workers হলো Cloudflare-এর edge সার্ভারে চলা ছোট ফাংশন।
2. আপনি JavaScript/TypeScript লিখে deploy করেন।
3. সারা বিশ্বের ৩০০+ ডেটাসেন্টারে এটা চলে, তাই latency খুব কম।
4. ফ্রি প্ল্যানে প্রতিদিন 100,000 অনুরোধ ফ্রি।
5. Workers-এ domain যুক্ত করা যায় "Worker Route" দিয়ে।

--------------------------------------------------------------------------------
পার্ট ২: ফ্রি প্ল্যান দিয়ে শুরু (ধাপে ধাপে)
--------------------------------------------------------------------------------
ধাপ ১: Cloudflare অ্যাকাউন্ট খুলুন
  - https://dash.cloudflare.com/sign-up
  - বিনামূল্যে অ্যাকাউন্ট তৈরি করুন (কার্ড লাগবে না)।

ধাপ ২: Workers সাবস্ক্রিপশন চালু করুন
  - ড্যাশবোর্ডে বাম মেনু থেকে "Workers & Pages" এ যান।
  - "Create Worker" চাপুন।
  - Worker-এর নাম দিন, যেমন: nebulaproxy-api

ধাপ ৩: Wrangler CLI ইনস্টল করুন (আপনার লোকাল মেশিনে)
  - Node.js ইন্সটল থাকতে হবে।
  - কমান্ড:

ধাপ ৪: লগইন
        wrangler login

ধাপ ৫: একটা নতুন Worker প্রজেক্ট তৈরি করুন

ধাপ ৬: src/index.js ফাইলে নিচের কোড দিন (নিচে পার্ট ৩ দেখুন)

ধাপ ৭: ডিপ্লয়
        wrangler deploy

--------------------------------------------------------------------------------
পার্ট ৩: Worker কোড (রোটেটিং API forwarder)
--------------------------------------------------------------------------------
নিচের কোডটা একটা "edges" API। এটা আপনার মূল সার্ভারের /api/proxy কে কল করে
রিজাল্ট দেখায়। (আপনার আসল সার্ভারের PUBLIC_API_URL বসান।)

=== src/index.js ===
export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    const backend = env.PUBLIC_API_URL || 'https://YOUR-SERVER.example.com';

    // CORS হেডার (ব্রাউজার থেকে কল করার জন্য)
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, OPTIONS',
      'Access-Control-Allow-Headers': '*',
    };
    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: cors });
    }

    const target = url.pathname.startsWith('/proxy')
      ? '/api/proxy' + url.search
      : '/api/status';

    const upstream = await fetch(backend + target, {
      headers: { 'X-API-Key': env.API_KEY || '' }
    });

    const data = await upstream.json();
    return new Response(JSON.stringify(data), {
      headers: { 'Content-Type': 'application/json', ...cors }
    });
  }
};
=== শেষ ===

-------------------------------------------------------------------------------
পার্ট ৫: Domain যুক্ত করুন (Workers-এ)
-------------------------------------------------------------------------------
1. ড্যাশবোর্ডে আপনার Worker খুলুন।
2. "Settings" > "Domains & Routes" এ যান।
3. "Add Route" চাপুন।
4. Route লিখুন, যেমন:  api.yourdomain.com/*
5. Zone (domain) সিলেক্ট করুন — এটা Cloudflare-এ থাকতে হবে (Nameserver Cloudflare-এ পয়েন্ট করা থাকতে হবে)।
6. DNS-এ api.yourdomain.com কে CNAME হিসেবে দিন:
        CNAME  api  ->  your-worker-name.your-subdomain.workers.dev

-------------------------------------------------------------------------------
পার্ট ৬: ফ্রি সাব-ডোমেইন যেভাবে পাবেন (যেহেতু কার্ড নেই)
-------------------------------------------------------------------------------
Workers সব Worker-কে একটা ফ্রি subdomain দেয়:
        <worker-name>.<subdomain>.workers.dev

এটাই ব্যবহার করতে পারেন কোনো টাকা ছাড়া। যেমন:
        nebulaproxy-api.rayhan.workers.dev

এছাড়া গ্রাহক-দৃশ্যমান সুন্দর ডোমেইনের জন্য (ফ্রি):
  • duckdns.org   → yourname.duckdns.org
  • freedns.afraid.org → অনেক ফ্রি subdomain
  • eu.org        → স্থায়ী ফ্রি real domain
  • js.org / is-a.dev → ডেভেলপারদের জন্য ফ্রি subdomain

সবচেয়ে সহজ: DuckDNS
  1. https://www.duckdns.org
  2. GitHub/Google/email দিয়ে লগইন (ফ্রি)।
  3. subdomain নাম দিন, যেমন: nebulaproxy.duckdns.org
  4. আপনার আসল সার্ভারের IP দিন।
  5. তারপর Cloudflare এ ওই ডোমেইন যোগ করে Workers Route দিন।

-------------------------------------------------------------------------------
পার্ট ৭: গুরুত্বপূর্ণ — গেটওয়ে (CONNECT) কোথায় চলবে?
-------------------------------------------------------------------------------
আবার মনে করিয়ে দিই: Workers কখনো CONNECT/raw TCP করবে না।
আপনার রোটেটিং গেটওয়ে (port 8000) চালাতে হবে একটা VPS-এ:
  • Railway / Render (ফ্রি টিয়ার আছে)
  • Fly.io (ফ্রি VPS-জাতীয়, $5 ক্রেডিট দেয় — তবে কার্ড চায়)
  • Oracle Cloud Always Free (কার্ড চায়, আপনি ব্যবহার করতে পারবেন না)
  • একটা পুরনো কম্পিউটার/Raspberry Pi + Cloudflare Tunnel (সম্পূর্ণ ফ্রি, কার্ড লাগে না)

সবচেয়ে ভালো ফ্রি অপশন (কার্ড ছাড়া):
  রাস্পবেরি Pi / পুরনো ল্যাপটপে Node.js চালান + Cloudflare Tunnel দিয়ে expose করুন।
  Cloudflare Tunnel (cloudflared) ফ্রি, কার্ড লাগে না, static IP-ও লাগে না।
