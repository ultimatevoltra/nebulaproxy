API Reference

Rotating proxy API

One endpoint. Rotates IP on every attempt.

EndpointDescription
POST /api/proxyRotate IP and fetch a target URL
GET /api/proxy/ipGet the current egress IP

Request fields

FieldTypeRequiredDescription
urlstringyesTarget URL to fetch through the proxy (https).
methodstringnoGET, POST, PUT, PATCH, DELETE, HEAD (default GET).
proxy_countrystringnous · gb · de · pl · es · jp · br · fr (default random).
retriesnumbernoAttempts (max 8, default 4). Each uses a fresh IP.
headersobjectnoExtra headers to forward.
bodyanynoRequest body (string or object).
bodyIsBase64booleannotrue when body is base64 (binary/file uploads).
stickybooleannoKeep one IP across steps for login flows.

cURL example

bash
curl -X POST /api/proxy \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://api.ipify.org?format=json",
    "method": "GET",
    "proxy_country": "us",
    "retries": 4
  }'

Python example

python
import requests

resp = requests.post("/api/proxy", json={
    "url": "https://api.ipify.org?format=json",
    "proxy_country": "gb",
    "retries": 4
})
print(resp.json())

Node.js example

javascript
const res = await fetch("/api/proxy", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    url: "https://api.ipify.org?format=json",
    proxy_country: "de"
  })
});
const data = await res.json();
console.log(data);
