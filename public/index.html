Documentation

API reference

Everything you need to integrate NebulaProxy into your app.

Endpoints

MethodEndpointDescription
GET / POST / PUT/api/proxyProxy a request through Cloudflare edge (supports query params or POST body)
GET/api/healthHealth check returning { status: "ok", version: "1.0.0" }
GET/api/versionReturns current version and edge engine metadata

Request parameters

FieldTypeRequiredDescription
urlstringyesTarget URL to fetch
methodstringnoHTTP method (default GET)
modestringnoauto (default), text, json, base64, stream
headersobjectnoCustom headers to forward to target
cookiesobject / stringnoCookies to attach to request
bodystring / objectnoRequest body (for POST/PUT/PATCH)
body_b64booleannoSet true if body is base64-encoded
timeoutnumbernoTimeout in ms (default 30000; returns 504 on expiry)
follow_redirectsbooleannoFollow redirects (default true)
filenamestringnoOptional Content-Disposition filename

Examples

cURL (Optional Token)
# Without auth (if API_TOKEN secret is not set):
curl "https://nebulaproxy.rayhan1789789.workers.dev/api/proxy?url=https://api.ipify.org?format=json"

# With auth (if API_TOKEN secret is configured):
curl -H "Authorization: Bearer YOUR_API_TOKEN" \
  "https://nebulaproxy.rayhan1789789.workers.dev/api/proxy?url=https://api.ipify.org?format=json"
Python
import requests

res = requests.get(
    "https://nebulaproxy.rayhan1789789.workers.dev/api/proxy",
    params={"url": "https://api.ipify.org?format=json", "mode": "json"}
)
print(res.json())
Node.js
const res = await fetch("https://nebulaproxy.rayhan1789789.workers.dev/api/proxy?url=https://api.ipify.org%3Fformat%3Djson");
const data = await res.json();
console.log(data);
