API reference

Everything you need to integrate NebulaProxy into your app.

Base URL

All API requests target your deployed Worker base URL.

https://nebulaproxy.rayhan1789789.workers.dev/api/proxy?url=...

Quick start (cURL)

Fetch any URL directly from your terminal:

curl -G "https://nebulaproxy.rayhan1789789.workers.dev/api/proxy" \ --data-urlencode "url=https://api.ipify.org?format=json"

POST with a body and headers:

curl -X POST "https://nebulaproxy.rayhan1789789.workers.dev/api/proxy" \ -H "Content-Type: application/json" \ -d '{"url":"https://httpbin.org/post","method":"POST","body":"{\"hello\":\"world\"}"}'

Response Envelope

For text/json/base64 modes, the proxy returns a JSON envelope:

{ "status": 200, "data": "...", // text/json/base64, depending on mode "data_b64": "...", // base64 of binary body "content_type": "...", "proxy_host": "edge", "attempt": 1, "elapsed_ms": 120, "size_bytes": 1234 }

For stream mode, the raw response body is streamed with the original Content-Type.
